CORE AGENT CHAIN

Step 1
🧭
CoordinatorAgent
意图分类 + Agent 链选择。解析用户查询，识别意图（kline / event / report / general），选择对应执行链。
输入: 用户查询
输出: intent + agent_chain + 路由元数据
→
Step 2
📥
IngestionAgent
数据加载与预处理。解析 JSONL/TXT/JSON 文件，调用 TextPreprocessor 清洗、切片、相关性过滤、文档分类。
输入: 原始文本/文件路径
输出: 标准化文档 + 元数据
→
Step 3
🧠
AnalysisAgent
统一分析引擎。按 intent 路由：指标抽取 + 实体识别 + K线技术分析 + 事件影响评估 + 报告生成。
输入: 路由任务 + 上下文文档
输出: metrics / entities / report / kline_analysis
→
Step 4
🛡️
ScoringAgent
质量校验与幻觉防护。HallucinationGuard 6 层校验 + PipelineScoreCard 各阶段打分。
输入: 分析结果 + 来源文档
输出: 评分报告 + 引用验证 + 最终回答
