6-Layer Hallucination Guard

L1 来源锚定25%jieba 分词 → 逐句 token 重叠率 ≥ 15% 视为有来源支撑
L2 数值一致15%提取「数字+单位」对，交叉比对检索源，防止编造数据
L3 引用完整10%[N] 标记存在且 N 对应有效来源，防止伪引用
L4 结构规范10%检测摘要/要点/分析/风险等预期段落是否存在
L5 LLM 质疑20%LLM 审查规则层结果，找出假阳性/假阴性
L6 LLM 协助20%LLM 独立逐句扫描，发现规则抓不到的幻觉

规则层(L1-L4) 总分低于 85% 时自动触发 LLM 层(L5-L6) · 每层得分透明嵌入最终输出
