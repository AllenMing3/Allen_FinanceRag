📐 架构概览 — 4 Agent + 3 保护层

4 Agent: CoordinatorAgent (路由) · IngestionAgent (摄取) · AnalysisAgent (分析/抽取/报告/K线) · ScoringAgent (幻觉防护)
3 保护层: DataOrchestrator (多池调度) · TextPreprocessor (清洗/切片/相关性) · LLMCaller (重试/缓存/JSON/约束)

INGEST PHASE — 数据摄取时运行

摄取时
📥
IngestionAgent
数据加载与预处理。将原始文件（JSONL/TXT/JSON/PDF）解析为统一文档格式，调用 TextPreprocessor 做清洗、切片、相关性过滤、文档类型分类。
输入: 原始文件
输出: 标准化文档 + 元数据 + CleanStats
→
摄取时
🗂️
DataOrchestrator
多池文本调度器。按文档类型自动路由到 KnowledgePool（financial_report / news / macro_data / general），支持跨池加权检索。
输入: 预处理后的文档
输出: 分池索引 + IngestStats (含拒绝原因)
→
构建时
🏗️
HybridRetriever (Index)
混合检索索引构建。对文档执行 BM25 分词索引 + Embedding 向量计算，准备 RRF 融合排序。
输入: 已分析的文档集合
输出: BM25 索引 + 向量矩阵

QUERY PHASE — 查询时运行

查询时
🧭
CoordinatorAgent
查询路由与调度。解析用户意图（KB查询 / 新闻分析 / K线 / 报告），选择对应 Agent 链执行，管理 5 阶段流水线。
输入: 用户查询
输出: 路由决策 → 调度 AnalysisAgent / ScoringAgent
→
查询时
🔍
HybridRetriever (Search)
混合检索 + RRF 融合 + Rerank。同时执行 BM25 关键词匹配和向量语义检索，通过 RRF 融合排序返回 Top-K 结果。
输入: 用户查询
输出: Top-K 相关文档 + 分数
→
核心
🧠
AnalysisAgent
统一分析代理。整合了原 ExtractionAgent / KLineAgent / EventImpactAgent / ReportAgent 的全部能力，按意图路由：指标抽取、实体识别、事件评估、报告生成、K线技术分析。
输入: 路由后的任务 + 上下文
输出: metrics / entities / report / kline_analysis
校验
🛡️
ScoringAgent
幻觉防护与质量评分。通过 HallucinationGuard (6 层校验) + SlotFiller 槽位填充，确保回答有来源支撑、数据准确。
输入: AnalysisAgent 的输出
输出: 评分 + 引用验证 + 最终回答

ANALYSIS PHASE — 智能分析（用户视角核心）

分析时
📰
News Analyzer
用户粘贴新闻 → AnalysisAgent 结构化抽取 → KB 上下文检索 → LLMCaller 研判，输出利好/利空/中性结论。
输入: 新闻全文 + 可选补充说明
输出: metrics + entities + assessment + KB sources
分析时
🔍
Topic Researcher
用户输入话题 → 自动抓取相关新闻（mock 可切换）→ KB 关联检索 → LLMCaller 综合研判，给出投资方向判断。
输入: 研究话题 + max_news
输出: news + assessment + KB sources

LLM CALL LAYER — 所有 LLM 调用的保护层

🔄
LLMCaller
智能调用层，封装所有 LLM 调用：① 重试机制 (指数退避) ② call_json() 结构化输出 (自动解析+重试) ③ 输入长度校验 ④ 响应缓存 (TTL) ⑤ 防幻觉约束。
替代: 原先各 tool 中的 llm.chat() + 手动 JSON 解析
提供: call() / call_json() / call_with_tools()
🧭
ModelRouter
智能模型路由：按任务复杂度自动选择模型 (turbo → plus → max → 235b)，预算控制 + 失败回退 + 调用统计。
提供: get_llm() / get_caller() / get_caller_for_agent()

🔄 数据流全景

文件→ IngestionAgent→ DataOrchestrator→ Knowledge Base→ HybridRetriever→ AnalysisAgent→ 回答
新闻→ News Collector→ Metadata Store (上下文) ··· 查询时作为补充上下文注入
粘贴新闻→ News Analyzer→ AnalysisAgent→ KB Context→ 利好/利空/中性
研究话题→ Topic Researcher→ News Collector→ KB Context→ 综合研判
股票代码→ AnalysisAgent (K线)→ 技术分析 (不存储)
所有 LLM 调用经 LLMCaller → 重试 + 缓存 + JSON + 约束 + ModelRouter → 模型选择
