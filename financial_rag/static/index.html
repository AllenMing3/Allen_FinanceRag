INGEST PHASE — 数据摄取时运行

摄取时
📥
IngestionAgent
数据清洗与标准化。将原始文件（财报、新闻、宏观数据）解析为统一文档格式，提取来源/时间等元数据。
输入: 原始文件 (JSONL/TXT/JSON)
输出: 标准化文档 + 元数据
→
摄取时
🔬
ExtractionAgent
关键财务指标抽取与实体识别。从文档中提取财务指标（营收、净利润、ROE）和实体（公司名、股票代码）。
输入: IngestionAgent 的输出
输出: metrics + entities → 附加到文档 meta
→
构建时
🏗️
HybridRetriever (Index)
混合检索索引构建。对文档执行 BM25 分词索引 + Embedding 向量计算，准备 RRF 融合排序。
输入: 已分析的文档集合
输出: BM25 索引 + 向量矩阵

QUERY PHASE — 查询时运行

查询时
🔍
HybridRetriever (Search)
混合检索 + RRF 融合 + Rerank。同时执行 BM25 关键词匹配和向量语义检索，通过 RRF 融合排序返回 Top-K 结果。
输入: 用户查询
输出: Top-K 相关文档 + 分数
→
查询时
📊
SlotFiller + HallucinationGuard
结构化槽位填充生成回答。基于检索到的上下文文档，通过 LLM 填充模板槽位生成最终回答，并由 6 层幻觉防护校验。
输入: 查询 + Top-K 文档
输出: 结构化回答 + 引用来源

ANALYSIS PHASE — 智能分析（用户视角核心）

分析时
📰
News Analyzer
用户粘贴新闻 → 结构化抽取（ExtractionAgent 复用）→ KB 上下文检索 → LLM/规则研判，输出利好/利空/中性结论。
输入: 新闻全文 + 可选补充说明
输出: metrics + entities + assessment + KB sources
分析时
🔍
Topic Researcher
用户输入话题 → 自动抓取相关新闻（mock 可切换）→ KB 关联检索 → LLM 综合研判，给出投资方向判断。
输入: 研究话题 + max_news
输出: news + assessment + KB sources

STANDALONE — 独立按需调用

按需
📈
KLineAgent
K线技术分析代理。从 Tushare 拉取行情数据，计算 MA/MACD/RSI/KDJ/布林带等技术指标，LLM 生成自然语言分析。结果不进入知识库。
输入: 股票名称/代码 + 时间范围
输出: 技术指标 + LLM 分析报告

SERVICE LAYER — 纯函数业务逻辑（services/）

🧠
services/analysis.py
智能分析纯函数。不依赖 HTTP/FastAPI，接受依赖注入（llm, retriever），返回结构化 dict。支持 mock 模式切换。
函数: analyze_news_text(), analyze_topic_research()
依赖: ExtractionAgent, HybridRetriever, News Collector
💾
services/persistence.py
持久化层。KB 文档、元数据、新闻归档的 JSON 读写。web.py 作为 thin shell 调用，不直接操作文件。
函数: load_kb(), save_kb(), load_meta(), save_meta(), append_news_archive()
存储: data/knowledge_base/

文件 → IngestionAgent → ExtractionAgent → Knowledge Base → HybridRetriever → SlotFiller → 回答

研究话题 → Topic Researcher → News Collector → KB Context → 综合研判
股票代码 → KLineAgent → 技术分析 (不存储)
