🧠 深度分析News / Topic / Follow-up

FinRAG 是一个意图驱动的多智能体 RAG 系统。用户输入自然语言查询，系统自动识别意图、选择合适的 Agent 链执行分析，并在最终输出前进行质量校验和幻觉检测。

4-AGENT 协作链

Step 1
🧭
Coordinator
意图分类 + Agent 链选择。解析用户查询，识别意图类型（K线 / 事件影响 / 报告 / 新闻 / 通用），选择对应执行链。
→
Step 2
📥
Ingestion
数据加载与预处理。文件摄取、文本清洗切片、相关性过滤，将原始数据转为可检索的知识库文档。
→
Step 3
🧠
Analysis
统一分析引擎。按意图路由到不同工具链：K线技术分析、事件影响评估、报告合成、新闻深度解读。
→
Step 4
🛡️
Scoring
质量校验与幻觉防护。6 层校验 + 各阶段打分，确保输出结果可信、可引用。
🔀 意图路由示例
“茅台走势” → K线分析链  |  “收购是利好还是利空” → 事件影响链
“财报分析” / “最新AI动态” → 完整分析链（摄取 + 分析 + 评分）
用户只需输入问题，系统自动决定执行路径
